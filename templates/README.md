# Templates

Browsable copies of the worked examples bundled with individual skills, collected here for easy showcasing. Each skill's own `examples/` folder is the canonical source; these are copies kept alongside for quick browsing without digging into `roles/`.

| Template | Skill |
|---|---|

To update a template, edit the canonical source linked at the top of each file, then re-copy it here - not the other way around, so the two don't drift out of sync.
