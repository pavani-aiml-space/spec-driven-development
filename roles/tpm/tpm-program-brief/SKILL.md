# Program Brief

## Purpose
**One job:** publish a **one-page** Hub-friendly summary distilled from `tpm-concept`.

For new programs, run **`tpm-concept` first**. Do not use this skill as a substitute for Concept.

## When to use
- Concept already exists and you need a short page linked from the Hub
- Re-publishing a skim version after Concept changed
- Not for stakeholder maps, RACI, or tooling

## Process
1. Open the current `tpm-concept` output.
2. Distill to one page: problem/vision, success criteria, in/out, timeline, sponsor.
3. Drop FAQ depth and research links (point back to Concept).
4. Publish as the Hub Program Brief page.

## Output
One-page brief on Confluence (or Markdown ready to publish).

## Handoff
**PMLC phase:** Concept / Work backwards (`tpm-pdlc`) — **optional** after `tpm-concept`.
Feeds Mechanism setup only as a Hub page. Align still uses Concept + `tpm-stakeholder-map` / `tpm-raci`.

## Checklist
- [ ] `tpm-concept` already exists
- [ ] Fits on one page
- [ ] Success criteria still measurable
- [ ] Links back to full Concept
